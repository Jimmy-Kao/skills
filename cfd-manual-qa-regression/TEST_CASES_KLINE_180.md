# 一通金业 180 版本需求（K线一期）测试用例

## Scope and assumptions
- 基于需求文档《一通金业 180版本需求（K线一期）》及本轮提供的 UI 截图。
- 用例采用 Google Sheets-ready 格式，中文输出。
- UI 未明确的细节在用例中标记为待确认或按当前截图状态验证。
